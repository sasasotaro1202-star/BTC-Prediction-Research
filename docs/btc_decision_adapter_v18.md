# BTC v18 Decision Adapter\n\nResearch-only bridge from the existing public-venue Shadow Situation Card to the v18 PredictionDecisionObject.\n\n## Boundary\n\nThe adapter does not calculate a prediction, probabilities, predictability, uncertainty, OOD score, failure probability, or model selection. The probability distribution must be supplied by the caller as an already-produced research value.\n\nFor each Situation Card, used_event_ids are resolved back to the normalized shadow events. A verified Decision Object is emitted only when every referenced event satisfies:\n\n- event_time_ms <= available_at_ms\n- available_at_ms <= prediction_time_ms\n- available_at_ms <= retrieved_at_ms\n\nThe provenance record stores source/type grouping plus deterministic hashes of event IDs and payload hashes. Missing or future evidence fails closed.\n\nA Situation Card with no used events becomes pit_status=deferred, not verified.\n\n## Production boundary\n\nThis module is research-only. It does not change:\n\n- production model selection;\n- production feature schema;\n- calibration artifacts;\n- promotion gates;\n- live prediction inputs.\n\nThe adapter is intended to make the v18 Decision Object replayable against shadow evidence before any OOS policy experiment is attempted.
